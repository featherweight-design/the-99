R1 Pull it · addendum · choosing the source deck

When two decks hold the card, Pull it asks which one gives it up.

Pull it gets a short list only when two or more decks could give the card up. The list is in commit order. Today's pick comes preselected, and the button says which deck it pulls from, so taking the default is still one extra tap. A locked copy is listed but can't be chosen. With one source, Pull it works as it ships. Source: pull-control.tsx, review-changes.tsx, availability.ts (pullSources), pull-release.ts at main. README and states · copy.

1 · Popover at 1300, sheet at 390. The popover hangs under the row, so the card it's about stays in view. A sheet would cover both columns for a two-to-four-row choice.
2 · Each source shows name, version and date, its new count, and new draft or joins its draft. Copies held is dropped: outside basics it's always 1, and basics never reach a pull.
3 · Today's pick is preselected. It's filled and the button names it, so the default can be seen, not just assumed. Commit order matches the contested-card row.
4 · Locked: shown and disabled, with its reason. It has the dashed edge and locked tag the shipped guard uses. Hiding it would make "in 3 decks" disagree with a list of two. Commander claims get the same treatment.
5 · One source: no list. The row already names the deck, so one tap pulls, as it does today, and Undo covers a mistake (3a).
6 · Confirm names the deck: Pull from HD - Avatar Aang. One sentence says what happens to that deck and how to undo it.
7 · After the pull the buy tag clears at once and the row reads pulled from HD - Avatar Aang, which links to that deck, where the undo lives.
Not listed: draft-only decks (no committed version, so they can't be a source) and junior decks. senior: false means pulling from them frees nothing. The list reads pullSources plus the guarded claims.

Frames are live: open the list, change the pick, confirm, replay.

4 · After the pull

The buy tag and the control go. The source deck takes the held-by slot, written as the past act and linked to that deck, where discarding its draft undoes the pull. The chips and the column note drop by one. The shipped announcement and focus handling are unchanged.
