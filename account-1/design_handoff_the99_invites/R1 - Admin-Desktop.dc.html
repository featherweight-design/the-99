An Invites column, an Invites tile and field per account, a top-up per group, and a tab for the tree

The group allowance’s controls, borrowed for a stock: a number field with the help line under it, the amber pending sentence that says what Save will do, Save and Undo, and a history line after. What changes is the meaning, and the words say it: an account’s field SETS how many it holds; a group’s is an action, “Top up invites to N”, that raises each member below N and lowers nobody, and the group keeps no number of its own. The tree is a sixth tab, Invites, because it reads across every account; a waiting invite is revoked there, and only there.
