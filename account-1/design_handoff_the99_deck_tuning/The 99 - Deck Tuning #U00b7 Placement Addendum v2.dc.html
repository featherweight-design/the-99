C · the lifecycle · 1300, one panel each

Tied to the version, not to Analyze. Analyze is free and near-instant; a run spends a credit. Running tuning on every Analyze would charge for a press the player believes is free, so the two stay separate presses. What ties them is the list: a set is made against one version, a commit retires it (C5), and a draft edit that breaks one swap marks that swap alone (C5, the row).

Notes are game notes only: the one-line deck_games.note a player types when logging a game. Version notes are not read. The row is labelled Notes on your games · on 2 of 9 games and the read line says 2 game notes, so neither can be mistaken for version notes. Deck intent, when set, is its own row.
