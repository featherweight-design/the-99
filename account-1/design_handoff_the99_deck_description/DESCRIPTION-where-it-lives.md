# Where the description lives. This replaces INTENT-where-it-lives.md

Ruling 1 (Hugh, 2026-10-03) reverses the old file's placement. It is owed a replacement rationale, not a silent override.

**What the old file said.** The ask lived inside the tuning panel, next to the payoff. There was no empty state in the header, and an always-editable header line was rejected because every deck would pay for one panel's benefit.

**What changed.** Two readers now use the description, not one. The overview reads it on the first Analyze press, so an ask placed inside Suggested changes arrives after the first overview has already been written without it. The only place that comes before both readers is the Analysis empty state, beside the press that starts them.

**What survives from the old rationale.**
- **There is still no header field and no header invitation.** A deck with no description draws no row (1f), and the old objection to making every deck pay still holds.
- **It is still optional and skippable by doing nothing.** The empty state has no Save and no skip link, because leaving it blank *is* the skip.
- **It is still quoted verbatim** to both readers, and never paraphrased.

**The doors, in order.**
1. Before a first reading: the empty-state field (1b–1d).
2. Always: the pencil on the deck name, which edits name and description together (1g).
3. While Suggested changes has never run and there is no description: `Describe your deck →` on its manifest row (1h), which opens door 2.

**The seeded line.** Ruling 3 clears auto-seeded lines, and nothing writes a new one. The provenance disc and the `from the build` chip go with it, so `intent_seeded` has no visual meaning left.
