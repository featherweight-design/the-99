# Six-column token table — The 99 theme system

`design/design_handoff_the99_themes/` · R1 · 2026-09-01

**This is the artifact eng implements from.** Every key below appears in all six theme blocks;
CI (theme spec, *Testing* rule 2) asserts set-equality against this list.

- **35 keys per theme** — 16 chrome · 6 accent · 3 semantic · 5 availability · 5 WUBRG.
- **Amonkhet is `:root`**; the other five are `[data-theme="…"]` blocks.
- `--avail-soft` and `--avail-hard` are **`var()` aliases, not literals** — write them as
  aliases in every block so they re-resolve per theme. Flattening them to hexes is a silent bug.
- `--kaiju-body`, `--celebrate-top`, `--celebrate-bottom` are **deleted**, not re-specified.
- `--brass*` → `--accent*` throughout, per the spec's Phase 1 rename.

### The one substantive reading

**§8.2's fifth column is the `--fg-faint` slot, not `--fg-muted`.** Read literally as
`--fg-muted`, §8.2 fails §8.9's own 4.5:1 floor in **four of six themes** — Neon Rain 3.81,
Screen Glow 3.36, Moonlit 4.00, Oil and Iron 4.04. Read as `--fg-faint` (floor 3:1), all six pass.

Amonkhet settles it: §8.2 gives `#8E8269`, which is `--fg-faint` in the shipped `globals.css`
**verbatim**, while shipped `--fg-muted` is `#A89B84`. This table therefore places the locked
values in `--fg-faint` and derives `--fg-muted` above them at Amonkhet's own muted-on-surface
ratio (6.36:1).
