Tools: fourteen tools, each on a real screen with its control haloed

About opens on Tools. Each tool is a card: a real screenshot cropped to the control that opens it, the tool’s name and cost, one line on what it is for, and Try it, which opens the tool on one of the reader’s own decks. Tools are grouped by when in a deck’s life a player reaches for them. A tool behind an off switch is not drawn; a tool whose moment was dismissed is drawn like any other.
