S3Two qualify on one visit: the first control on screen wins, the other waits

The brief’s case: a deck at 99 / 99, opened for the first time at 100, with a Shopping row over its $10 limit. Both Suggested changes and Cheaper stand-ins qualify. On load, Suggested changes’ control (the Analysis tab) is on screen and stand-ins’ (a Shopping row’s ⇄) is not, so Suggested changes takes the visit. When the player then opens Shopping on the same visit, the over row draws no bubble. Stand-ins is not spent: it fires on a later visit, the first time that row’s ⇄ is on screen. Had both controls been on screen together, the fixed order on the calls board decides (Suggested changes, 5, before Cheaper stand-ins, 8).
