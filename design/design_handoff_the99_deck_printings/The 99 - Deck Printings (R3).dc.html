The rule (Hugh, 2026-10-10). It applies to a spoken-for card, the only kind with a pick and a buy tag. If the pick is in stock, the tag prices it. If it isn't, the tag shows the cheapest printing that is in stock, which is today's price. If nothing is in stock, the tag is the shipped buy · sold out. No new tag style and no new copy (Hugh, 2026-10-10). The fallback is an edge case, and the figure is what a buyer acts on, so the tag reads exactly as it does on main. Over the limit measures the figure on the tag, the fallback included. The Shopping total sums what's shown. I got it presets the printing behind the figure, so a fallback presets the in-stock printing (the audit's recommendation). It still never writes the pick. Card details are unchanged.
