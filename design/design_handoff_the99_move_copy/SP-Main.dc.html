Move a copy: several decks can be picked

Hugh’s case: 5 Fabled Passage, 6 decks want it. Today one pick per card exists, so moving the copy from HD - Gishath to HD Tune - Mutant Menace is impossible: picking Mutant Menace takes the copy from Multiverse Reforged, and picking Gishath lights it up and changes nothing. Ruling: picks up to the number of copies owned. Picked decks get a copy, the oldest unpicked decks fill the rest, the newest unpicked deck goes without. Every frame is the shipped component rendered from main (shipped CSS, Amonkhet) with this proposal applied; rows, marks and accent are the shipped chooser’s.

Calls

1

A picked deck reads “your pick · gets it”, accent square mark and accent border (shipped pick). A deck with its copy by commit order keeps the neutral mark and its date: “v5 · Oct 1 gets it”. The words carry who chose it, so the hue is never the only signal.

2

Every select on an unpicked deck adds a pick until the picks reach the copies. On a deck that buys it, it gets a copy and the deck marked “gives it up first” flips to “buys it”. On a deck that already gets it, the pick keeps its copy whatever is picked later. Order never changes.

3

Select a picked deck again to untick it. Its copy goes back to commit order: the oldest deck going without gets it back (P4). One control per action, so no Clear all link; the shipped “Back to first committed” stays retired.

4

Every copy picked (2+ copies): the heading reads “5 of 5 picked” and a line under the rows says “All 5 copies are picked. Untick one to give another deck a copy.” It shows as soon as the last pick lands, before anyone tries. A select on the unpicked deck writes nothing and announces that line (P5).

5

Who goes without, before and after. Before a select: the newest unpicked deck holding a copy reads “gets it · gives it up first”, so the player sees which deck a new pick will take from. After: that row flips to “buys it” on the same select, and the hint moves up to the next one (P1 → P2 → P3).

6

The heading counts picks: “2 of 5 picked” once any pick stands; with none it keeps the shipped “5 of 5 given”.

7

One copy is unchanged. Round mark, one pick, a select on another deck moves it (shipped single-select). An Other decks pick still counts toward the cap, as R1b ruled.

The same states on the other surfaces

C

Card details, In your decks: a picked deck reads “holds 1 · your pick” in accent (C2, C3), replacing “gets it”, since a pick always gets a copy. Commit order rows keep “holds 1 · gets it” / “holds 1 · buys it”. Change is unchanged.

H

History’s “Went to” line: the record never changes. “Now X has it.” is added only when the deck it went to holds no copy now, and X names only the decks a pick put a copy in (H2: “Went to HD - Gishath. Now HD Tune - Mutant Menace has it.”). Today X lists every holder, which on a 5-copy card would name five decks.

L

A large entry’s Can move tab (the History entry’s last tab): the same rule on each card row’s own line (L2). Change opens the same chooser.

D

Desktop: the chooser is the shipped 520 modal with one-line rows; the hint and “your pick” sit in the outcome slot (D1–D3). Card details receipt (D4), History (D5), Can move (D6).
