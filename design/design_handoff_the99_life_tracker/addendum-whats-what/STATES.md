# What's what · states

| State | What shows | Drawn |
|---|---|---|
| First play on this device | Guide arrives once the first-player roll has landed (or Start, with I'll pick) + 600 ms. Flag set as it shows. | T1, P1 |
| First play, flag already set | Nothing. | — |
| Resume a kept game, Rematch, next game | Nothing (the flag is per device, not per game). | — |
| Menu open | First row What's what, then Back to the table. Focus on What's what. | T2, P2 |
| What's what pressed | Menu closes; guide shows over the board as it is now. | T3 |
| Not your turn | End turn's label points at the active panel's End turn, wherever it is. | — (T1/T3 have it on yours) |
| No badges on you | No What's on you label. | T1, P1 |
| Badges on you | What's on you label on the badge row. | T3 |
| Your panel flipped out | Life, End turn and badge labels drop; the panel's Undo isn't labelled (it says what it does). Strip labels stay. | — |
| Sheet, dice or pick in progress | First-open waits until none is open (R1 arrival rule). The Menu closes the dice popover already. | — |
| Game over (Result showing) | Not shown; the Menu row isn't reachable. | — |
| Closing | ✕, a tap anywhere, Esc. Focus returns to Menu (or to the board on first open). | — |
| Reduced motion | No fade in or out. | — |
| Storage unavailable | Guide shows on first open of each visit; Menu row works as normal. | — |
