Shared, not one-off

TileSkeleton lives in ui/ beside CardTileCaption and is built from TILE_SHELL, TILE_ART_RATIO and TILE_ART_CLIP, so it is any grid's tile. Precons adopt it now. Collection, Discover, Decks, Sets and Tokens adopt it when each route's loading is next touched, not in this round.

Tiles or rows

The skeleton follows the view this browser stored (the precons view cookie): rows when it says rows, else tiles. A URL carrying view=rows also means rows. So the loaded page lands on the same layout it was promised.
