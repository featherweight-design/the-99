Sender fixture: Colin, with Ghalta, Primal Hunger as his commander.

The answer in one line

Every email The 99 sends sits on the brand’s Table Candlelight ground: the crowned 99 and the wordmark on top, one panel with a Georgia heading, one brass button or one big code, and a footer that says why it came and that replies aren’t read. The friend invite leads with the sender’s own invitation card, tilted, exactly as the newcomer page draws it.

Product calls, closed by Hugh: Clerk’s two code emails are branded in Clerk’s editor and still sent by Clerk. Ours (invite, newcomer code, flyer code) go through Resend from invites@. The invite shows the sender’s commander art, with a plain version. No reply-to.

Design’s six calls (the brief’s Open list)

1

The shell

A fluid column, 600 max, on the base ground #14110E. One panel (#1E1A15, 1px #3A3229, 12 radius, 40px padding, 24 on a phone). Heading Georgia bold 26, body system sans 16/1.6, fine print 14 under a hairline, footer 13 in the fine-print color. One button style: brass, 8 radius, 48 tall, dark label, VML for Outlook. Tables and inline styles only; the one <style> block only tightens padding on a phone, and the layout holds without it. Board S.

2

Header and mark

The crowned 99 tile (hosted PNG, 36px, alt="") beside the wordmark as live text, Georgia bold, letter-spaced. With images off the mark drops and THE 99 still reads; an alt text in a 36px box clips (board D). Cinzel won’t load in most clients, so no web font is linked anywhere: Georgia is what every client shows, the same everywhere.

3

The invite, in detail

Subject as today. Preheader “Join as Colin’s friend. The link works for 7 days.” The sender’s invitation card (the shipped compact FriendCard: name, commander art, “Invitation”, the rules line, the art credit) as one hosted PNG with the −3° tilt baked in, since mail clients drop transforms. Then the heading, one line on what The 99 is, Join The 99, the raw link under it, a hairline, the 7-day and ignore line. No art: no card, three brass diamonds over the heading instead; a grey “No commander” card is a poor first sight. No name: “A friend”, as today. Boards I and P.

4

Which emails get the shell

All five. The newcomer and flyer codes share one template, the code 34px mono, letter-spaced, live text with no spaces in it so a copy or a phone’s code autofill gets six clean digits; the code stays in the subject too. Clerk’s sign-in and reset codes are the same shell for Clerk’s editor, with {{otp}} marked. Boards C and K.

5

Dark mode

A dark shell, declared dark (color-scheme: dark), so Apple Mail and iOS Mail leave it alone, and partial-invert clients (Outlook, Gmail on Android) have no light ground to flip. Gmail on iOS inverts even dark mail: it comes out parchment with dark ink and a deep brass button, drawn and legible. Images never invert, so the mark tile and the card keep the brand in every client. Board D names each color.

6

Plain text

First line is the lead sentence, not the subject again (it is what an inbox previews). The link or the code on its own line after a short label, then -- and the same footer words. Board T.

For Hugh · one question

Q1 · Clerk’s From address. The brief suggested hello@. With no reply-to and a footer that says replies aren’t read, “hello” invites a reply nobody sees. Recommended: codes@, display name “The 99” on every sender line. Clerk defaults to noreply@ if left empty.

Gaps for engineering

G1 · The card image. The app draws the invite card as a PNG (360×480 source, shown 180×240) from the shipped compact face, on the app’s origin, at a URL keyed by the reservation (not guessable, not the sender’s public id) that works for 7 days. Art fetched server-side. If it can’t be drawn, send the plain version. The name is drawn as text, cut with an ellipsis like the shipped name bar.

G2 · The mark PNG. /email/mark-96@2x.png on the app’s origin, the app icon with brass diamonds. design/ is never copied to public/, so the build makes it; art/mark-96@2x.png is the reference.

G3 · Clerk’s editor. {{otp}} is not in Clerk’s documented variable table (it lists action_url, app.*, invitation.*, inviter.name): confirm it with the editor’s Variable insert, and that HTML mode keeps tables and inline styles and the subject takes a variable. Turn Clerk branding off. The “10 minutes” line must match Clerk’s code lifetime.

G4 · Clerk’s account emails (verify an added address, password changed, new sign-in) take the code shell’s pattern: heading, one line, fine print. Eng confirms which are on before drawing words for them.

G5 · A client test pass (Gmail iOS, Android and web, Apple Mail, Outlook 365 and Windows, Yahoo) before ship. The Gmail iOS frames here are a simulation.

G6 · Copy review. Every string is in emails · copy strings.ts; run /copy-review before the build.
