## Locks held

| Lock | How R1 holds it |
|---|---|
| Reopening a past run is free | No model call on list or open; the note says so; no credit pill in History. |
| A run is read-only | No edit in place; `Change answers` is the shipped way to ask anew. |
| Runs are per account | Own rows only. |

| Reading never calls the model | List and open are stored reads. |

| Screen reader | Row name carries the words (or answers line) and the date; opening focuses the title, announced as a past run, read-only. |
| Switch | Off: nothing drawn, nothing linked, route not found. |
| Model input | Showing the words back sends them nowhere; only the form's press does. |
