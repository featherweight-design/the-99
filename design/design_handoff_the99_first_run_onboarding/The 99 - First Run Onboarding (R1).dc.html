Typing REPLACE does not survive. The gate existed because the step could not be undone, and Hugh has ruled that it can. Continue → on the review screen is already the first deliberate press, and this dialog is the second. A third, typed gate would treat a reversible step as a disaster, which is what ruling 5 rejects.

Neutral ink throughout. There is no icon, no --danger and no --warning, since colour is status and nothing here has one. The primary is the ordinary bone fill. The "can't be undone" sentence goes, and a now → after figure pair replaces it. The pair is what a player actually weighs.

The button counts what you get: "Replace with 1,212 cards" (the matched count), where today it counts what you lose. Focus opens on Keep current, so Enter never replaces. Escape and the backdrop close it, but not while pending, as today. Pending reads "Replacing…". Copy is placeholder, and /copy-review sets it.
