# States · alternate printings from search (R1)

| State | Trigger | Set field | Region |
|---|---|---|---|
| Unowned, closed (U1) | card details from search, 2+ printings | `N printings ▾` | none |
| Unowned, open (U2) | Set field press | `▴` | all printings; ◇ Shown now = catalog main; search + set headers past 12 |
| Unowned, previewing (U3) | select a tile | caption = previewed set · number | ◇ moves; art and price follow; nothing stored |
| Owned, closed (O1) | own 1+ printings | `N printings · you own K ▾` | none |
| Owned, open (O2) | Set field press | `▴` | In your collection (shipped picker), then Other printings; no finish chips |
| Owned, pick + preview (O3) | pick an owned tile, then select another | `◆ Your pick · N printings` | ✓ on the pick, ◇ on the preview; picking an owned tile ends the preview |
| One printing (X1) | catalog has 1 | plain field + `The only printing` | no disclosure |
| Close / page | ✕, Esc, swipe, Prev/Next | — | preview forgotten |
| Add to collection while previewing | shipped press | — | Edit copies opens with the previewed printing as the new printing |
