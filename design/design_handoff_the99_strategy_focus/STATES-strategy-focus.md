# Strategy focus · states (R2g, approved)

| State | Trigger | What shows | Board |
|---|---|---|---|
| No focus | Default | Ring, empty dashed circle at the centre, radios empty; line "No focus yet. Pick one and Suggested changes will build toward it." | Focus-Flow 1 |
| Focus picked | Press a legend row | Arc pulled out in accent, the focus's icon on the medallion, radio filled, row tinted; line "Focus Tokens: Suggested changes builds toward it. Keep it balanced" | Main |
| Focus cleared | Keep it balanced | Back to No focus | — |
| Suggested changes ready | Open the tool with a focus | Shipped panel + manifest row "This deck's focus · Tokens" + one lead sentence | Focus-Flow 2 |
| Swaps | Run returns | Shipped two lists; additions toward the focus carry `focus · Tokens 11 → 12` | Focus-Flow 3 |
| Applied | Add / Cut / Apply all | Shipped answered rows, Apply the rest | Focus-Flow 4 |
| Graph after changes | Any pending change since the last commit, from any source | Lighter arc, legend `11 +2` (a cut: `−N`, arc shrinks) until the next commit | Focus-Flow 5 |
| One to four strategies | Fewer score | Only those arcs and rows | Graph-States |
| Nothing over the floor | No axis scores | One box: "No strategy stands out yet." No pick | Graph-States |
| Too early to read | Under 30 nonland | One box: "Too early to read." | Graph-States |
