## The picker

| State | What draws | Board |
|---|---|---|
| Results, a commander that chooses a Background | Its row adds `chooses a Background` under the name | P1, D1 |
| Results, any other commander | Shipped: one line, seats on press | P1, D1 |
| Background step, empty, nothing typed | Head (‹, art, name); `Search Backgrounds`; the rule line; `Seat Lae’zel`; foot | P2, D2 |
| Typing, one letter | Rule line stays; nothing searched (shipped two-letter floor) | rule only |
| Searching | Shipped `Searching…` | rule only |
| Hits | Background rows: art, name, pips | P3, D3 |
| No hit | `No Background by that name.` | rule only |
| Search failed | Shipped `Couldn’t search just now. Try again.` | rule only |
| Chosen | `BACKGROUND`, chosen row, `Change` · `Remove`; `Seat Lae’zel + Raised by Giants` | P4, D4 |
| Change pressed | The search returns, field focused; the chosen Background stays until another is pressed | rule only |
| Remove pressed | Slot empty; `Seat Lae’zel` | P6, D5 |
| ‹ pressed | Back to the commander search (a friend's, when reached from a friend); the step's picks are dropped | rule only |
| Seat pressed | The seat fills (commander, or the pair) and the picker closes, as a commander press does today | P5 |
| Reopened from a seat whose commander chooses one | Opens on the step: chosen when the seat has a Background, empty when not | P6 |
| Reached from a friend's Another commander | Same step; Seat seats the friend with the pair | rule only |
| Esc, ✕, a press outside (desktop) | Closes; nothing changes on the seat (shipped) | — |
