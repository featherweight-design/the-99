The call

  1. Confirm all as built. The shared component is the design; the boards drew one-offs before the shared piece was picked. No code change.
  2. The handoff PR records each in the three handoffs’ READMEs as an erratum pointing here, so the next round draws from the built sizes.
  3. One rule going forward: a board that uses a toast, sheet, modal, switch, key or text link draws the shared one at its shipped size.
