Arrange: centred on desktop, and inside a folder

In a folder the sort menu’s row names the folder and counts its decks. Arrange lists only those decks.

PHONE · ARRANGE SIMIC
DESKTOP · ALL DECKS, CENTRED 720PX COLUMN
DESKTOP · ARRANGE SIMIC
DESKTOP · IN THE SIMIC FOLDER, SORT MENU OPEN

Centred: heading, Cancel / Done and rows share one 720px column, so the eye doesn’t travel to the far right to finish.

Folders (rec: allow): one saved order. Arranging Simic swaps those two decks with each other; every other deck stays where it was in All decks.

Alternative: All decks only. Simpler to build, but changing a folder’s order then means finding its decks in the full list. The deck strip inside a folder reads “‹ Simic”.
