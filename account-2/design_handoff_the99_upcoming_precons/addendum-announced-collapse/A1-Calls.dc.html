How a large reveal collapses in the Announced group

Hugh’s brief: Star Trek’s fifteen revealed commanders draw a block about 2,400px tall on a phone. Tile size and card details are closed (#1808). This settles the collapsed count, the control, memory, the threshold, and desktop.

01
Collapsed row count, per widthOne row: as many tiles as the grid has columns at that width.

2 at 390 (and every width under 480), 4 at 900, 6 at 1300; between those, whatever the auto-fill grid lays out (150px floor to md, 178px from md). The count is read from the grid itself, not hard-coded, so it is always exactly the first row and never a ragged half row.

02
The thresholdNothing collapses until the commanders fill three rows. Two rows always stay whole.

In counts: collapse when revealed > 2 × columns. That is 5 or more at 390, 9 or more at 900, 13 or more at 1300. Hiding a second row of two saves less than it costs to press; at three rows the box is already taller than the first screen on a phone. The common case (2) and one row’s worth never show a control at any width (P3, D3, D4).

03
The controlThe app’s shared SheetGroupToggle, as it is: “Show all 15” closed, “Show fewer” open.

Same 12.5px medium accent label and disclosure chevron the Change commander and swap sheets use, with aria-expanded and aria-controls naming the set’s grid. It sits under the grid inside the dashed box, left-aligned with the tiles (no 43px indent), 44px tall at 390 and 34px from md. Inside the dashed box it drops its own bottom rule: the box’s edge already closes it, and two lines read as a double border. That needs one prop on the shared component (G1). Spoken names say which set, since two big sets would each carry one: “Show all 15 commanders revealed for Star Trek Commander” and “Show fewer Star Trek Commander commanders”.

04
Expanding and collapsingIn place, with no animation; focus stays on the toggle.

Show all reveals the rest of the grid under the first row and the toggle moves to the foot. Show fewer folds it back; if the toggle would then sit above the top of the window, the page scrolls just enough to keep it in view, so a reader at the bottom of fifteen isn’t dropped into the decklists. Hidden tiles are hidden (out of the tab order and the reading order). Card details still pages all of the set’s commanders, because card details is closed for this round.

05
Does it remember being open?For the visit, not across visits.

Each set’s open state lives with the visit’s other Announced state (useAnnouncedVisit in the list view), keyed by set code, so closing and reopening the group or switching to rows and back keeps it. The next visit starts collapsed again, the way a set row in rows view starts closed every visit. Nothing new is stored: no key, no cookie, and the server draws it collapsed.

06
While a filter is onNothing collapses.

A search or a colour that narrows a set’s commanders draws every match, the same way a filter opens the group by itself. The reader asked for those cards, and hiding some of them behind a press would read as “no match”.

07
DesktopYes, desktop collapses too, by the same rule.

Fifteen at 1300 is three rows, about 1,070px of block, which pushes the decklists below the first screen of a 900px window. One rule at every width is easier to learn and to test than a phone-only exception, and the group is closed by default anyway, so this only applies once a reader has opened it.

08
List view (rows)Not affected.

The set row is its own disclosure, closed every visit; opened, its strip scrolls sideways at 390 and wraps at 900 and up (two lines for fifteen at 1300). Board A1 · Rows shows it.

Gaps for engineering
G1

SheetGroupToggle always draws a bottom rule (it appends border-b outside the merge). Inside the dashed box the rule should go: one optional prop (e.g. rule={false}), default unchanged for the two sheets.

G2

Before hydration the server cannot know the column count between breakpoints. Engineering decides how to draw the first paint with no jump; one way is CSS that hides tiles past the first row at the column counts PRECON_TILES_CLASS produces at each breakpoint, refined by a measurement once mounted.

G3

Card details opened from tile 1 and paged to a hidden tile returns focus to an element that can’t take it. The provider’s return-focus walk already falls back to the disclosure whose aria-controls names a hidden region; confirm it finds the set’s toggle from a hidden li, or point it there.

G4

Card images and names are stand-ins cropped from Hugh’s precon screenshots. Star Trek’s real fifteen aren’t readable from this environment.

G5

Copy: showAll(n) “Show all N”, showAllAria(n, set), showFewer “Show fewer”, showFewerAria(set), in preconsCopy.upcoming. No About entry: this is a layout change to a shipped surface, not a feature.
