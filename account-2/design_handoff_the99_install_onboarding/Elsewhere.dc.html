I4Android · the row

Only while a beforeinstallprompt is held. Line: Full screen and one tap away. Your phone asks once. Select calls prompt(), and Chrome's own install dialog opens. It isn't drawn here, because it's the browser's UI. If the player accepts, the row goes on appinstalled. If they decline, the row goes for this visit, since Chrome holds no prompt again for a while. It comes back only when a prompt is held again.
