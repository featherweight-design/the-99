# Overview iteration 3: samples

Three decks, each a self-contained static HTML page (inline CSS, no scripts, no external assets) showing today's
stored Overview beside the iteration-3 shape, with the eval harness's checks under the new side. Taken from local
eval runs (`overview-stages-3`, and `overview-stages-3-fix-ci` for Counter Intelligence), which are gitignored.

- [counter-intelligence-precon-alternate.html](counter-intelligence-precon-alternate.html): a precon with an
  alternate commander (Kilo, Apogee Mind); shows the precon-only alternate line.
- [mutant-menace-precon.html](mutant-menace-precon.html): a second precon whose shape and land checks pass. Every
  precon in the run carries an alternate commander, so this one does too.
- [brago-player-deck.html](brago-player-deck.html): a player's own deck (Brago, King Eternal). The alternate line is
  absent and labelled as such.
