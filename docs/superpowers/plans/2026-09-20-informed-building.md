### Task 1: `playableAsLand` — the third land answer

`isLandFace` answers "was this played as a land" from the front face alone, which is correct for
the curve and wrong for the question the fill asks: *could* this card have been a land drop.
A `modal_dfc` with a land back could; a `transform` card could not.

**Files:**
- Modify: `src/lib/cards/facet.ts`
- Test: `src/lib/cards/facet.test.ts`

**Interfaces:**
- Consumes: nothing.
- Produces: `playableAsLand(typeLine: string, layout: string | null): boolean` — true when the
  front face is not a land but the card can still be played as one. Returns **false** for a card
  whose front face already is a land, because that card is counted by `isLandFace` and counting
  it twice is the bug this separation exists to prevent.

```ts
/**
 * Whether the card COULD be played as a land, though its front face is not one.
 *
 * The third land answer in this file, and it is a different question from both of its
 * neighbours. `cardFacet` buckets a row for a grouping strip. `isLandFace` decides whether a
 * card contributed a mana value to a curve. This one decides whether the card can take a land
 * drop, which is what the fill needs before it decides how many lands to add.
 *
 * `layout` IS THE TEST, never the type line. 50 catalog rows are `modal_dfc` and 32 are
 * `transform`; both read `Something // Land`, and only the first can be played as a land from
 * hand. A `transform` card is cast as its front face and flips later, so `Ojer Axonil,
 * Deepest Might // Temple of Power` is a creature you cast, never a turn-one land drop.
 * Counting the 32 as land-capable was the defect this function exists to prevent, and a
 * `type_line` test cannot see it.
 *
 * Returns FALSE when the front face is already a land. That card is counted by `isLandFace`,
 * and a card counted by both would be added twice wherever the two are summed.
 */
export function playableAsLand(typeLine: string, layout: string | null): boolean {
  if (layout !== "modal_dfc") return false;
  if (isLandFace(typeLine)) return false;
  const faces = typeLine.split(" // ");
  if (faces.length < 2) return false;
  return /\bland\b/.test(faces[1].toLowerCase());
}
```

**Where it runs and why.** A final pass in `build-commander-index.ts`, not in `build-staples.ts`.

892,185 rows on staging. Classify the DISTINCT catalog once (~31,830 commander-legal cards) into

between two rows naming the same card.

- [ ] **Step 3: Implement**

```ts
import { classifyRoles, type Role } from "../../src/lib/recs/roles";

export type RoleDerivationRow = {
  commanderOracleId: string;
  oracleId: string;
  /** EDHREC's percentage, 0.3 to 100. */
  inclusion: number;
  typeLine: string;
  oracleText: string | null;
  keywords: string[];
};

export type RoleTargetRow = { ramp: number; draw: number; removal: number; wipes: number };

const ROLES = ["ramp", "draw", "removal", "wipes"] as const;

/**
 * The expected number of cards filling each role in a deck for this commander.
 *
 * A PROBABILITY SUM, not a count: a card listed at 50% inclusion contributes 0.5 to every role
 * it satisfies, because that is how many copies of it the average deck holds.
 *
 * A card counts toward EVERY role it satisfies, unlike the fill, which spends a card on the
 * first role it can close. The two are answering different questions — this describes what
 * decks contain, the fill plans what to put in one — and making them agree would make this
 * figure depend on an ordering that has nothing to do with the decks it is measuring.
 */
export function deriveRoleTargets(
  rows: readonly RoleDerivationRow[],
): Map<string, RoleTargetRow> {
  // Classified ONCE per distinct card. `classifyRoles` is pure, so two rows naming the same
  // card cannot disagree — and the pair-wise form is 892,185 regex passes on staging against
  // ~31,830 here.
  const rolesOf = new Map<string, Role[]>();
  const out = new Map<string, RoleTargetRow>();

  for (const row of rows) {
    let roles = rolesOf.get(row.oracleId);
    if (!roles) {
      roles = classifyRoles({
        typeLine: row.typeLine, oracleText: row.oracleText, keywords: row.keywords,
      });
      rolesOf.set(row.oracleId, roles);
    }
    let target = out.get(row.commanderOracleId);
    if (!target) {
      // Zero rather than absent: 369 commanders measure a genuine 0 for wipes, and a column
      // that cannot tell "none" from "not derived" is a column nobody can read.
      target = { ramp: 0, draw: 0, removal: 0, wipes: 0 };
      out.set(row.commanderOracleId, target);
    }
    if (!Number.isFinite(row.inclusion) || row.inclusion <= 0) continue;
    const p = row.inclusion / 100;
    for (const role of ROLES) if (roles.includes(role)) target[role] += p;
  }
  return out;
}
```
