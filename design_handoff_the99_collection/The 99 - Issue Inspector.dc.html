Anatomy · token references
Dialog / sheet
Desktop: 660px, #1A160F / 1px #3A3229, radius 16px, shadow 0 40px 100px rgba(0,0,0,.7). Backdrop rgba(8,6,4,.72) over the blurred review page. Mobile: full-screen sheet on #14110E.
Tabs
Plex Sans 600 14px. Active #EDE6D8 + brass underline (inset 0 -2px 0 #C9A24B); idle #8E8269. Count pill Plex Mono 11px, tinted to state color; disabled at 0 uses success + not-allowed. role=tab/tablist, aria-selected.
Filter input
#181410 / 1px #3A3229, radius 8px, 40/44px tall. Leading ⌕ glyph; trailing ✕ clear when filled. Focus ring 3px rgba(201,162,75,.16) + brass border. First-focusable on open.
Unmatched row
Status-row pattern: #1E1A15, 1px #2A241D, 3px left border #E0913C, radius 8px. Name Plex Sans #EDE6D8 (ellipsis); line · set · reason Plex Mono #8E8269; ×qty trailing. ~40px tall.
Parse-error row
Same shell, 3px left border #C6533F. Leading L#### line badge (Plex Mono, 46px fixed col); reason Plex Sans #C6B79A, offending value bolded #EDE6D8. Reason-first, no qty.
Count · match · zero-states
Count Plex Mono 11px #8E8269; turns #E0913C at Showing 0. Match highlight rgba(201,162,75,.28) wash. Empty-filter uses the card-fan mark + Clear filter (brass). Empty tab: success-bordered zero-note, hoisted to the top of the dialog.
Scale / density. Rows are ~40px (desktop) / ~38px (mobile), single-line with ellipsis. The scroll region is a fixed-height overflow-y:auto body; the dialog height is capped so the header, tabs, and filter stay pinned. Max rendered target: ~150 rows via plain overflow-y:auto; above that, virtualize the list body (react-window or equiv) — the worst case is 200+ entries per tab. Filtering is client-side substring over the already-loaded unmatchedRows / parseErrors payload; no new fetch.
